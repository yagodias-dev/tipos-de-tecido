# Histologia na Enfermagem — Tecido Epitelial e Conjuntivo

Landing page de estudo, guiada por imagens, para estudantes de enfermagem.
HTML, CSS e JavaScript puros (a única dependência externa é a fonte do Google Fonts, que tem alternativa do sistema).

> **Status:** Etapa 1 de 4 concluída (estrutura, design system, hero, menu e tecido epitelial).
> Este README será completado na Etapa 4.

## Como abrir

Abra `index.html` no navegador (duplo clique). Não precisa de servidor.
Para testar como site, rode um servidor local na pasta, por exemplo: `npx serve .` ou `python -m http.server`.

## Estrutura

```
index.html     página única com todas as seções
style.css      design system (cores, tipografia, tema claro/escuro) e componentes
script.js      tema, menu, progresso, hotspots, esquemas SVG, galeria, lightbox
IMAGENS.md     lista das lâminas a baixar (nome do arquivo + termo de busca)
README.md      este arquivo
assets/img/    salve aqui as imagens baixadas
```

## Imagens

Veja `IMAGENS.md`. Salvando o arquivo com o nome indicado em `assets/img/`, a foto substitui
a caixa cinza automaticamente.
